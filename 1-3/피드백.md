# 민수 님께 보내는 피드백

민수 님, 영화 티어리스트를 직접 써 봤어요.

**잘된 점**

- S·A·B·C 칸마다 색이 달라서 어느 칸이 어느 등급인지 한눈에 알 수 있었어요.
- 위쪽에 "9편 중 1편 나눔"처럼 진행 상황이 보여서, 영화를 옮길 때마다 얼마나 남았는지 알 수 있었어요.
- 카드를 옮길 때마다 "‘기생충’을 S에 놓았어요."처럼 결과를 말해 줘서 잘 옮겨졌는지 바로 알 수 있었어요.
- 제목에 띄어쓰기가 있는 영화(센과 치히로의 행방불명 등)도 끌어서, 눌러서 모두 옮겨졌어요.

**고치면 좋을 점**

1. 본 것: 영화 하나를 S칸으로 옮기고 새 영화를 추가한 뒤 브라우저를 새로고침했더니, S칸이 비고 추가한 영화도 사라졌어요. 위쪽 표시도 "8편 중 0편 나눔"으로 돌아갔어요.
   기준: 기획서의 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다"
   제안: 영화를 추가하거나 옮길 때마다 브라우저에 저장해 두고, 파일을 다시 열면 저장된 내용으로 시작해 주세요. "처음으로"를 누를 때만 처음 8편으로 돌아가면 돼요.

2. 본 것: 24인치 모니터에서 브라우저 창 가로를 절반쯤으로 줄이기 시작했더니 오른쪽이 가려졌어요. 폭 약 900px로 열었더니 "처음으로" 버튼과 위쪽 "8편 중 0편 나눔" 표시의 오른쪽 끝이 잘렸고, 가로로 밀어서 볼 수도 없었어요. 휴대폰 같은 좁은 화면에서는 더 많이 잘릴 것 같아요.
   기준: 기획서의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"
   제안: 페이지 폭을 960px로 고정하지 말고 화면 폭에 맞춰 줄어들게 해 주세요. 좁은 화면에서는 위쪽 헤더와 입력창을 아래로 내려서 배치해 주세요.

3. 본 것: 입력칸을 비우거나 공백만 넣고 "추가"를 눌렀더니 이름 없는 카드가 생겼고, 안내에 "‘’를 추가했어요."라고 나왔어요.
   기준: 기획서의 "제목을 입력하면 새 영화 카드가 생깁니다"
   제안: 제목이 비어 있으면 카드를 만들지 않고 "영화 제목을 입력해 주세요"라고 알려 주세요.

4. 본 것: 영화 카드가 모두 같은 연한 회색이라 단조롭고 칙칙하게 느껴졌어요.
   기준: 기획서에는 없어서, 쓰면서 불편했던 점으로 적어요. 카드가 모두 같은 색이라 구분하거나 고르기 어려웠어요.
   제안: 카드마다 색을 다르게 하거나, 등급 색과 어울리는 은은한 색을 써 주세요.

5. 본 것: 영화 카드를 끌어서 S칸에 놓으려고 하니 "아직 안 정한 영화"가 맨 아래에 있어서, S칸과 함께 한 화면에 보이지 않았어요(창 높이 약 660px 기준으로 S칸 맨 위와 영화 목록 사이가 약 730px). 그래서 화면을 스크롤하며 끌어야 했어요. 카드를 누르고 등급 글자를 누르는 방법도 있었는데, 이 방법은 위쪽 작은 글자 한 줄로만 안내되어 있어서 처음엔 눈에 잘 안 띄었어요.
   기준: 기획서의 "카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다"
   제안: 영화 목록 위치는 기획서대로 두고, 눌러서 옮기는 방법이 있다는 안내를 카드 영역 근처에 눈에 띄게 보여 주세요. 예를 들면 "카드를 누른 뒤 S·A·B·C 글자를 눌러도 돼요" 같은 문구예요.
