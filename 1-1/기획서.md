# 영화 티어리스트 기획서

## 1. 누가 쓰나

- 본인이 본 영화를 티어(S·A·B·C·D)로 나눠 정리하고 싶은 개인 사용자 한 명이 쓴다.
- 로그인 없이 자기 브라우저에서 혼자 쓴다.

정하지 않은 것:

- 여러 사람이 함께 쓰거나 온라인으로 공유할지 여부 (이번 버전에서는 하지 않는다)

---

## 2. 무엇을 하려고

영화 제목을 카드로 추가하고, 마우스로 끌어서 S·A·B·C·D 칸에 놓아 나만의 영화 티어리스트를 만든다.
한 번 만든 배치는 파일을 닫았다가 다시 열어도 그대로 남아 있어야 한다.

이번 버전에서 하는 것:

- 영화 제목 추가
- 영화 카드를 드래그해서 티어 칸으로 이동
- 영화 삭제
- 배치 저장 (브라우저 `localStorage` 사용)

이번 버전에서 하지 않는 것:

- 회원가입, 로그인, 온라인 공유
- 포스터 이미지, 장르, 감상 메모, 세부 평가 점수
- 통계 화면, 차트
- 영화 정보 수정 화면, 데이터 내보내기·가져오기
- 여러 파일로 나눈 구조, 외부 라이브러리

---

## 3. 화면과 동작

화면은 한 페이지이고, 위에서 아래로 다음 순서로 보인다.

1. **제목 영역**: "영화 티어리스트" 제목
2. **추가 영역**: 제목 입력칸과 "추가" 버튼
3. **티어 칸**: S, A, B, C, D 다섯 줄. 각 줄은 왼쪽에 티어 이름, 오른쪽에 영화 카드가 놓이는 영역
4. **미분류 칸**: 아직 티어를 정하지 않은 영화가 놓이는 영역

동작:

- 제목을 입력하고 "추가"를 누르면 영화 카드가 **미분류 칸**에 생긴다. (Enter 키로도 추가할 수 있다.)
- 영화 카드를 마우스로 끌어서 다른 티어 칸이나 미분류 칸에 놓으면 그 칸으로 옮겨진다.
- 영화 카드의 삭제 버튼을 누르면 그 카드가 사라진다.
- 추가·이동·삭제할 때마다 배치가 자동으로 저장된다.
- 화면 문구는 모두 한국어로 쓴다.

정하지 않은 것:

- 화면 색상과 디자인 (어두운 배경 / 밝은 배경 등)
- 삭제할 때 확인 메시지를 띄울지 여부
- 처음 열었을 때 예시 영화를 미리 넣어 둘지 여부
- 같은 칸 안에서 카드 순서를 바꿀 수 있게 할지 여부
- 스마트폰 터치로 끄는 동작을 지원할지 여부

> 참고: "미분류 칸"은 새 영화가 처음 놓일 자리가 필요해서 넣었다. 이 부분은 사용자가 확인해야 한다.

---

## 4. 필요한 자료

- 티어 이름: `S`, `A`, `B`, `C`, `D`
- 영화 한 편의 정보: 고유 번호, 제목, 현재 있는 칸 (S/A/B/C/D 중 하나 또는 미분류)
- 저장 위치: 브라우저의 `localStorage`
- 결과물 형식: HTML·CSS·JavaScript가 모두 들어 있는 `.html` 파일 하나. 외부 파일, 외부 라이브러리, 서버 없이 브라우저에서 바로 열린다.

정하지 않은 것:

- `localStorage`에 저장할 때 쓰는 이름
- 티어 칸 색상

---

## 5. 완성 기준

아래 항목을 하나씩 직접 해보고, 모두 맞으면 완성이다.

1. 파일을 더블클릭하면 서버나 인터넷 없이 브라우저에서 열리고, 화면 문구가 한국어로 보인다.
2. 입력칸에 "인셉션"을 쓰고 "추가"를 누르면 "인셉션" 카드가 미분류 칸에 나타난다.
3. 입력칸이 빈 채로 "추가"를 누르면 빈 카드가 생기지 않는다.
4. "인셉션" 카드를 끌어서 S칸에 놓으면 카드가 S칸으로 옮겨진다.
5. S칸의 "인셉션"을 끌어서 B칸에 놓으면 S칸에서는 사라지고 B칸에 나타난다.
6. 새로고침하거나, 브라우저 탭을 닫았다가 파일을 다시 열어도 "인셉션"이 B칸에 그대로 있다.
7. 영화를 여러 편 추가해 서로 다른 칸에 나눠 놓고 다시 열어도, 모든 영화가 놓았던 칸에 그대로 있다.
8. 카드의 삭제 버튼을 누르면 카드가 사라지고, 다시 열어도 돌아오지 않는다.
